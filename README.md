# AI Trust Ledger User App

This repository contains the Android User app for the **AI Trust Ledger** platform.

## Overview

The AI Trust Ledger User App allows end users to interact with the AI Trust Ledger ecosystem from their mobile devices. Users can sign in, view and manage their personal ledger entries, and stay up to date with the latest data in the ledger. The project is built with Kotlin and follows modern Android development practices.

## Features

- User authentication and login
- Dashboard to display ledger entries
- Ability to create, update and view ledger transactions
- Integrates with the AI Trust Ledger backend services
- Material Design user interface

## Getting Started

1. **Clone the repository**

   ```sh
   git clone https://github.com/shayann07/AI-Trust-Ledger-User.git
   ```

2. **Open in Android Studio**

   Import the project into Android Studio. Make sure you have the latest stable version of Android Studio installed.

3. **Sync Gradle**

   Allow Android Studio to sync and download the required dependencies.

4. **Configure backend endpoints**

   Update any API base URLs or tokens in the configuration files as needed to point to your AI Trust Ledger backend.

5. **Run the app**

   Connect an Android device or start an emulator, then run the app from Android Studio.

## Technologies Used

- Kotlin / Java
- Android SDK, Jetpack Libraries (ViewModel, LiveData)
- Firebase / Google Services
- Gradle build system
